Ark Wallet SDK Now Available

The Ark Wallet SDK is a TypeScript library for building Bitcoin wallets with support for both on-chain and off-chain transactions via the Ark protocol. The Ark protocol is a Bitcoin Layer-2 solution that allows users to transact off-chain using Virtual Transaction Outputs (VTXOs) which are batched by a server into regular on-chain transactions, with users maintaining the ability to exit unilaterally to the main chain at any time.
