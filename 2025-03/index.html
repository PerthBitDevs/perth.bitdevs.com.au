Bitcoin Inquisition v28.1 Released

Bitcoin Inquisition is a signet full node designed for experimenting with proposed soft forks and other major protocol changes. This version has support for ephemeral dust, which is part of the ephemeral anchors idea that would allow Lightning on-chain transactions to have fees set at spend time. Any participant can use the ephemeral anchor output as the input to a child transaction which adds fees at the time the transaction is broadcast.

github.com - Bitcoin Inquisition v28.1 Release bitcoinops.org - Ephemeral Anchors

Kagi Implements Privacy Pass

Kagi implements Privacy Pass, an authentication protocol that allows clients to authenticate to Kagi servers in a way that verifies the client has the right to access its services but does not reveal the identity of the connecting client.
